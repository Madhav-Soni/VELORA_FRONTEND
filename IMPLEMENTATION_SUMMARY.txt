ANIMATION SPECIFICATIONS
═══════════════════════════════════════════════════════════════════════════

Hover Animation:
   Scale:            1.0 → 1.08 (8% increase)
   Duration:         0.3s
   Easing:           ease-out
   Shadow:           Enhanced glow effect

Entry Animation (VeloraLogoFull):
   Initial:          opacity 0, scale 0.95, y -25px
   Final:            opacity 1, scale 1, y 0px
   Duration:         0.7s
   Type:             Spring physics

Splash Animation (VeloraLogoSplash):
   Icon:             Rotate 180° + scale in (spring)
   Text:             Fade in with 0.4s stagger
   Dots:             Pulse animation (0.8s cycle)
   Total:            ~2.5s sequence

Glow Effect (VeloraLogoDark):
   Pulse:            Opacity 0.3 → 0.6 → 0.3
   Duration:         3s cycle
   Effect:           Breathing cinematic presence
